# 🔄 Lab Workflow

## 1. Active Directory Preparation

Prepared the on-premises Active Directory environment for identity synchronization.

Activities included:

- Active Directory configuration
- User management
- Group management
- Organizational structure preparation
- Preparing identities for synchronization

---

## 2. Microsoft Entra Connect Sync

Configured Microsoft Entra Connect Sync to synchronize identities between the on-premises Active Directory environment and Microsoft Entra ID.

Activities included:

- Microsoft Entra Connect installation and configuration
- Directory synchronization
- Identity synchronization validation
- User synchronization testing

---

## 3. Microsoft Entra Cloud Sync

Configured Microsoft Entra Cloud Sync as an identity synchronization solution.

Activities included:

- Cloud Sync configuration
- Provisioning configuration
- Active Directory integration
- Identity synchronization testing
- Synchronization validation

---

## 4. User & Group Management

Managed identities and groups within Microsoft Entra ID.

Activities included:

- User creation and management
- Security Group management
- Dynamic Group configuration
- Dynamic membership rules
- Group membership validation

---

## 5. Microsoft Entra ID P2

Configured Microsoft Entra ID P2 licensing within the lab environment.

Activities included:

- Microsoft Entra ID P2 license configuration
- License assignment
- Identity management validation

---

## 6. Azure Policy & Governance

Implemented Azure governance controls using Azure Policy.

Activities included:

- Policy assignment
- Policy configuration
- Governance control implementation
- Allowed Virtual Machine Size SKUs policy
- Policy compliance configuration

---

## 7. Policy Enforcement Testing

Tested Azure VM deployments against the configured governance policies.

Activities included:

- Attempting VM deployments
- Testing allowed VM sizes
- Testing restricted VM sizes
- Analyzing policy-denied deployments
- Validating policy enforcement
- Reviewing compliance results
