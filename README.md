# 📂 Projects

## 1. 📱 Microsoft Intune Endpoint Management, Security & Remote Support Lab

Hands-on Microsoft Intune lab covering Windows and Android device enrollment, endpoint management, application deployment, compliance policies, endpoint security, device configuration, Scope Tags, Managed Google Play, and remote support.

📁 **Project:** `Microsoft-Intune-Endpoint-Management`

---

## 2. 🔐 Microsoft Entra Identity, Synchronization & Azure Governance Lab

Hands-on Microsoft Entra ID and Azure Governance lab covering Microsoft Entra Connect Sync, Cloud Sync, Active Directory integration, identity management, Dynamic Groups, Microsoft Entra ID P2, Azure Policy, and VM governance.

📁 **Project:** `Microsoft-Entra-ID-Azure-Governance`

---

## 3. ☁️ Azure Enterprise Network Lab

Hands-on Azure enterprise networking lab covering Virtual Networks, Subnets, Network Security Groups, Windows Server VMs, IIS, Azure Load Balancer, Health Probes, Load Balancing Rules, Azure VPN Gateway, and Point-to-Site VPN.

📁 **Project:** `Azure-Enterprise-Network-Lab`

---

## 4. 🖥️ Active Directory Infrastructure Lab

Hands-on Windows Server 2025 Active Directory infrastructure lab covering Active Directory Domain Services, Domain Controller, DNS, Organizational Units, Users, Groups, and Group Policy.

📁 **Project:** `Active-Directory-Infrastructure-Lab`

---

## 5. 🐍 Network Path & OSPF Cost Simulator

Python-based networking project using Dijkstra's Algorithm to simulate OSPF path selection and calculate network paths based on link costs.

📁 **Project:** `Network-Reachability-Checker`

---

## 6. 🏛️ Smart Museum System

IoT Graduation Project focused on museum monitoring using sensor-based detection.

### Main Components

- Metal Detector
- Flame Detector
- Infrared (IR) Sensor
- Sensor-Based Monitoring
- Automated Alerts

📁 **Project:** `Smart-Museum`

---

## 7. ☁️ Microsoft 365 Administration & Security Lab | MS-102

Hands-on Microsoft 365 administration and security lab covering Microsoft 365 user and license management, Administrative Units, Microsoft 365 Apps deployment, Exchange Online, Microsoft Teams, SharePoint Online, Microsoft Entra ID, Microsoft Defender, Attack Simulation Training, Microsoft Purview, Data Loss Prevention (DLP), retention, and Microsoft 365 Groups.

📁 **Project:** `Microsoft-365-Administration-Security-Lab-MS-102`
