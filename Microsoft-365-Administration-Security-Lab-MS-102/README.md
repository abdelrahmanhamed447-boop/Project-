# Microsoft 365 Administration & Security Lab | MS-102

📌 **Overview**

A hands-on Microsoft 365 administration and security lab covering practical configuration and management tasks across Microsoft 365 services.

The project includes user and license management, Microsoft 365 Apps deployment, Exchange Online, Microsoft Teams, SharePoint Online, Microsoft Entra ID, Microsoft Defender, Attack Simulation Training, Microsoft Purview, and Microsoft 365 Groups.

## 🎯 Project Objectives

- Administer Microsoft 365 users and licenses.
- Configure Administrative Units and administrative roles.
- Manage user passwords and account settings.
- Deploy Microsoft 365 Apps using the Office Customization Tool.
- Configure Exchange Online resources and transport rules.
- Configure Microsoft Teams and team membership.
- Manage SharePoint Online resources.
- Manage Microsoft Entra ID users and devices.
- Configure Microsoft Defender security policies.
- Configure and validate Attack Simulation Training.
- Configure Microsoft Purview compliance features.
- Configure Data Loss Prevention (DLP) and retention settings.
- Create and manage Microsoft 365 Groups.
- Configure dynamic group membership.

## 🔄 Project Workflow

1. **Microsoft 365 User & License Management**
   - Created and managed Microsoft 365 users.
   - Assigned and managed licenses.
   - Configured user account and password settings.

2. **Administrative Units & Role Management**
   - Created Administrative Units.
   - Added users and groups.
   - Assigned administrative roles and administrators.

3. **Microsoft 365 Apps Deployment**
   - Created an Office Customization Tool configuration.
   - Configured installation, updates, languages, licensing, and activation settings.
   - Prepared and deployed Microsoft 365 Apps.

4. **Exchange Online**
   - Configured Exchange Online resources.
   - Created and configured a Room Mailbox.
   - Configured a Transport Rule.

5. **Microsoft Teams**
   - Created and configured Teams.
   - Managed team members and membership.
   - Reviewed Teams administration settings.

6. **SharePoint Online**
   - Accessed SharePoint administration.
   - Managed and reviewed SharePoint Online resources.

7. **Microsoft Entra ID & Device Management**
   - Reviewed Microsoft Entra users and devices.
   - Worked with registered and joined devices.
   - Reviewed device registration and user-device associations.

8. **Microsoft Defender**
   - Configured and reviewed security policies.
   - Worked with Anti-Phishing, Anti-Spam, and Anti-Malware policies.

9. **Attack Simulation Training**
   - Configured phishing simulation scenarios.
   - Configured target users and simulation settings.
   - Reviewed and validated the configuration.

10. **Microsoft Purview**
    - Configured compliance and information protection settings.
    - Worked with Data Loss Prevention (DLP).
    - Configured retention-related settings.

11. **Microsoft 365 Groups & Dynamic Membership**
    - Created and managed Microsoft 365 Groups.
    - Configured dynamic membership rules.
    - Reviewed and verified group membership.
